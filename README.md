# SiteMoth downloads

Official distribution repository for [SiteMoth](https://sitemoth.bitswot.com).

Installers will be available on the Releases page after release validation is complete. No installer has been published yet.

- macOS: Apple Silicon; Developer ID signed and notarized releases.
- Windows: x64; installers are currently distributed without a code-signing signature.

This repository contains release files and accompanying third-party notices/source materials. It does not contain the proprietary SiteMoth application source code.
